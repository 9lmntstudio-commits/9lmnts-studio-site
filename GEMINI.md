## 1. Antigravity Quantum Vault (AQV) Pre-Flight Law
- **Mandatory Pre-Flight Snapshot:** Before executing any multi-file refactor, directory deletion, or structural overhaul, always verify that an AQV snapshot exists or trigger:
  ```bash
  node antigravity-vault.js snapshot --label "pre_flight"
  ```
- **Disaster Recovery:** If unintended file corruption or accidental deletion occurs, instantly restore from the latest snapshot using `antigravity-vault-backup` skill or `node antigravity-vault.js restore <id>`.

## 2. Quick-Start Reusability: How to White-Label for a New Client

To white-label or adapt this design system for a new beauty/skincare brand in under 5 minutes:

### Option A · Dynamic In-Browser Rebranding (Zero-Code)
1. Open the live page: `https://9lmntsstudio.com/demo/belfanm`
2. Press **`Shift + B`** on your keyboard to reveal the **⚡ Founder Brand Switcher** drawer.
3. Type the new brand name and origin city. The entire UI (logo, titles, metadata) updates in real time.
4. Or share a client demo URL with query parameters:
   - `https://9lmntsstudio.com/demo/belfanm?brand=Lumière+Botanics&origin=Paris+×+Montreal`

### Option B · Standalone Project Export
1. Copy `public/demo/belfanm/` and `public/assets/belfanm/` into any new static hosting directory (Cloudflare Pages, Netlify, Vercel, or S3).
2. Update the vibrant color tokens in `index.html` (`:root`):
   ```css

   --accent: #F5A623;          /* Sun-Drenched Amber Gold */
   ```

   - No container boxes, no card borders, no rounded rectangle grey tiles.
